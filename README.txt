A PARFUME — ETIR SATISI IDAREETME SISTEMI

WINDOWS-DA ISHE SALMA:
1. ZIP faylini sag klik -> Extract All / Извлечь все.
2. Cixarilmis A_PARFUME qovlugunu ac.
3. run_windows.bat faylina iki defe bas.
4. Qara pencere aciq qalmalidir.
5. Brauzerde http://127.0.0.1:5000 ac.

ILK ISHE SALMA INTERNET TELEB EDIR: Flask paketi yuklenir.
Python 3.11+ qurasdirilmalidir. Python qurasdiranda "Add Python to PATH" secin.

FUNKSiyalar:
- Icmal ve satis statistikasi
- Mehsul elave etme: etir adi, brend, nov (Hazir flakon/Doldurma), hecm ml,
  alis qiymeti, satis qiymeti, stok
- Satis qeydiyyati ve stokdan avtomatik cixilma
- Hesabatlar ve CSV ixraci
- Melumatlar a_parfume.db faylinda saxlanilir.

QEYD:
Hazir flakon ucun stok ededle, doldurma ucun stok ml ile daxil edilmelidir.
Sistem lokal komputerde 127.0.0.1:5000 unvaninda isleyir.
Qara pencerani baglasan sistem dayanacaq.
